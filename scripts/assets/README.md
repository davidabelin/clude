# Door sample source

`door-source.wav` is a 1.5-second excerpt from LeonMire's “Squeaky door.ogg”,
PDSounds record 505. The recording is released into the public domain; its
[Wikimedia Commons file page](https://commons.wikimedia.org/wiki/File:Squeaky_door.ogg)
records the source and licence.

The excerpt covers 5.65–7.15 seconds of the original, converted to mono,
22.05 kHz, 16-bit PCM. The first 100 ms of the earlier cut were removed to
drop its opening beep. `scripts/make_sounds.py` adds a faint short reflection,
boosts low frequencies around the closing impact, and speeds the excerpt up
slightly to fit a door animation.
