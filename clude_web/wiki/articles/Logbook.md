A **logbook** is a character's memory between games. After a game played with a language model in the seat, the model is shown the whole deal face up and writes an entry in the character's voice: what happened, a judgement of each opponent, what it learned, and a list of standing instructions for next time. Before the next game it reads back as much of the logbook as its *memory* setting allows.[^logbooks]

Three characters, [[Colonel Mustard]], [[Mrs. White]] and [[Mr. Green]], also have a memory inside their methods, kept as numbers and updated whether or not a model is playing. The one long experiment with a written logbook is described at [[Professor Plum#Memory|Professor Plum]].
